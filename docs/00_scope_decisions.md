# Scope decisions

| Decision | Choice | Reason |
|---|---|---|
| Feed | Dry outer birch bark, 5,000 t/yr | Side stream of Finnish plywood/pulp mills |
| Operating time | 8,000 h/yr (about 625 kg/h) | Standard continuous plant basis |
| Products | Betulin (>=95% purity), suberin-derived fatty acids, Extractives | Project goal |
| Extraction solvent | Hot ethanol-water mixture | NaOH | Common in the literature, easy to model |
| Operating conditions| Temperature(60-100°C), Timing varies | Common in the literature, easy to model |
| Operating mode | Continuous (simulation basis) | Suits DWSIM steady-state and dynamics |
| Depth | Conceptual design | One flowsheet, one dynamic section, 2 HAZOP nodes |
| Tools | DWSIM(transferable to Aspen HYSYS, Python, draw.io | Open source, reproducible |
